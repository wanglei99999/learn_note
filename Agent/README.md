# Agent

agent 原理笔记，是[深度学习](../深度学习/README.md)系列的姊妹篇。全系列共 13 篇，从一次模型调用写起，每篇往外加一层：先讲上一层在哪里出了问题，再讲这一层怎么补上。第 03 篇给出全系列的定义 Agent = 模型 + Harness，之后的每一篇都在往 harness 里加一个部件，最后一篇拿 Claude Code 对照全部内容。

文中不放可执行代码，需要时用伪代码。配图在 `assets/` 下，画图的脚本在 `assets/src/`。讲到模型训练、KV Cache、采样等内容时会链接到深度学习系列。
