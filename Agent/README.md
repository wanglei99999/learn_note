# Agent

agent 原理笔记，是[深度学习](../深度学习/README.md)系列的姊妹篇。全系列共 13 篇，从一次模型调用写起，每篇往外加一层。每一篇围绕一个技术论点展开：先说明这一层面对的约束，再把机制拆到消息、token 和成本的层面，用示意数字和推导说明取舍的条件。第 03 篇给出全系列的定义 Agent = 模型 + Harness，之后的每一篇都在讲 harness 的一个部件从哪条约束里推出来，最后一篇拿 Claude Code 对照全部内容。

文中不放可执行代码，需要时用伪代码。构造的例子和数字都标明“示意”，可以手算核对。配图在 `assets/` 下，画图的脚本在 `assets/src/`。讲到模型训练、KV Cache、采样等内容时会链接到深度学习系列。
